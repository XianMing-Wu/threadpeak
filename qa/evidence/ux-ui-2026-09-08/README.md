## 方案落实范围

| 方案项 | 本轮处理 |
| --- | --- |
| 2.1 标题对比度 | 浏览器确认白色渐变文字与灯光背衬对比不足；改为实色标题、副标题独立段落，移除灯效 |
| 2.2 输入名称 | 主输入、浏览搜索、画布搜索拥有可访问名称 |
| 2.3 作者关系图 | React 稳定节点、键盘选择/平移/缩放/复位、指针与键盘高亮切换、文本等价列表关联 |
| 2.4 设置确认框 | 原生 dialog、取消初始焦点、Escape、背景隔离和触发焦点恢复 |
| 2.5 标题层级 | 中文首页 h1、3D/404 h1、列表与文档层级；移除标题上的错误 textbox 角色 |
| 2.6 空与错误状态 | 同步首页编选补空态；真实目录加载用骨架，读取失败可重试且不被搜索空态覆盖，已读取内容继续保留 |
| 2.7 明暗主题 | 首次跟随系统、显式选择持久化、首绘主题、登录与内部面板共用语义 token |
| 2.8 / 3 / 4.3 字号与样式体系 | 拆分全局职责，统一字体/颜色/圆角/阴影/字号，移除旧私有皮肤，保留必要第三方覆盖 |
| 4.1 首页结构 | 真实编选封面、非对称知识推荐、横向路线浏览、清晰示例身份 |
| 4.2 市场差异 | 现场 concepts 是旧记录的概念详情而非第二个主导航页；保留入口并明确概念级文案，不合并产品路由 |
| 4.4 / 4.5 字体与 constellation | 统一跨平台无衬线；已无活动入口的旧 constellation 样式删除，真实作者网络与第三方 3D 语义保留 |
| 4.6 动效 | 统一状态动画与全局减少动效；建议支持暂停/键盘浏览；减少动效时空态 GIF 改用静态素材 |
| 4.7 / 4.8 / 4.9 | 阅读内容用间距/分隔组织；筛选按钮采用 aria-pressed；历史显示自然日分组，卡片采用列表语义 |
| 4.10 窄屏 | 统一 560/760/1080 断点，导航背景隔离、提交后焦点恢复、学习区域和操作控件适配 |
| 浏览器追加修复 | 首页旧选择器裁切、图卡嵌套交互、边缘卡工具栏、代码/长公式键盘横滚 |

## 复现

按 [QA 入口](../../README.md) 启动独立测试 API 与前端，再运行：

```sh
PLAYWRIGHT_MODULE=/path/to/node_modules/playwright AXE_MODULE=/path/to/node_modules/axe-core UX_QA_URL=http://127.0.0.1:4404/ node scripts/verify-ux-ui-browser.mjs
```

测试脚本使用真实组件检查主题、键盘、搜索恢复、来源不变、编辑、新对话及 3D 返回；合成作者关系图位于 [独立 QA 页](../../ux-ui-lab.html)。仅浏览器测试可使用这些合成资料，正式请求不能回退为测试结果。
