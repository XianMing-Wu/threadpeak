# 终点浮层裁切与回弹修复（2026-09-08）

范围：本地示例路线、真实 WebGL 渲染器、终点详情卡与“走到这”。不涉及 provider 或生产验收。

上游源码修复保存在 [本次增量](upstream-source.patch)，以修复前的现有工作树为基准，不包含上游已有改动。由上游的 `build:module` 脚本生成整包，19 个文件与 ThreadPeak 的 vendor 逐字节一致，摘要见 [生成物清单](../../../../../vendor/learning-path-3d-manifest.json)。没有手改 bundle。

- 卡片定位器与渲染器的上移限制原先不一致，短窗口下镜头过早停住。
- 画布拖动边界原先包含临时卡片偏移，抵消上移并改写画布位置。现用基础镜头计算边界，再应用浮层偏移。
- 窄屏卡片实际只余 12px 留白，定位器却持续追求 20px，导致横移、投影丢失与反复回弹。现按实际空间收敛。

[浏览器报告](report.json) 记录窗口尺寸、逐帧反向位移、卡片边界及按钮实际移动结果；同目录 `frames-*.json` 保存原始轨迹，`goal-*.png` 保存截图。检查从可见的第一帧开始，禁止卡片在稳定过程中重新隐藏，正常动画的反向位移容差为 1px；减少动效时允许带边框视口在立即定位后进行 2px 内的一次校正。两者稳定后的位移均须小于 1px。超矮窗口允许卡片内容内部滚动。

运行入口：`scripts/verify-path-card-placement.mjs`，使用 `PLAYWRIGHT_MODULE` 指定 Playwright，默认访问隔离 QA 源 4404；`PATH_CARD_QA_URL` 可指定其他本地 QA 源。

上游类型检查、体验 smoke、页面组合根回归和模块边界检查分别验证源码与公开入口；ThreadPeak 的常规门禁另记在本目录日志。静态通过与浏览器通过分别记录。
