## 不应混淆的结论

- 本次真实调用的是知乎搜索；示例讲解和访谈经过编选，不是一次完整线上 Agent 运行的成功率测量。
- 论文是明确的公开阅读锚点，NumPy 是四篇公开文章的示例选集，不冒充用户上传文件或授权收藏。
- API 原摘要自身缺式或含有不支持的表达式时，仍完整保留并显示原有阅读提示；原文损坏不等于编选讲解缺式，更不声称修复了作者原文。
- 本轮没有生产部署，没有重新验收 OAuth、PostgreSQL、全量压缩质量或生产负载。离线用例和演示页面通过不代表这些门槛完成。
