# 登录页视觉重设计验收 · 2026-09-09

本次范围：AuthLanding 构图、字体、按钮、球体背景和帮助说明。功能基础为[双登录验收](guest-login-2026-09-09.md)，视觉规则见[登录视觉](../docs/login-design.md)。未更改模型、知乎搜索或路线编排。

## 当前结果

- 两栏构图，冷白／炭黑与品牌紫；本地中文可变字体和同宽胶囊按钮。字体由浏览器 CSS.getPlatformFontsForNode 确认真正参与中文标题绘制，不仅检查 CSS 声明。
- 球体填充展示区并位于文字后面，保留用户指定的慢速细线旋转。去掉左下角孤立标语；三项产品能力和标题、说明归为一组。
- 游客记录说明绝对定位成浮层。1440×690 实测展开前后展示区尺寸同为 685.203125×530px；键盘 Enter 可展开，焦点环清楚。
- 独立 Chrome 对 1920、1440、1024、800、390、320px 宽度检查；690px 高度下双登录按钮均在实际应用可视区域内，无横向溢出。窄屏内容可纵向滚动，页脚不与登录区重叠。
- 浅色、深色、窄屏截图人工查看；Canvas 相隔多帧确有变化，系统减少动效时保持同一帧。
- 实际走游客登录、公开搜索范围菜单、文件上传、刷新、退出后恢复、设置无 OAuth、知乎演示授权跳转/回调、收藏夹出现、账号隔离、切回游客。没有在用户原浏览器中清理 Cookie 或资料。

## 检查与证据

本轮 `npm run check`、`npm run lint`、`npm test`、`npm run build` 均通过；完整回归为 449 项服务/单元测试与 71 项 UI 测试。最后一次能力说明与帮助布局调整后重跑 UI 与构建，结果记在同一内部目录。字体为本地 65,744 字节 WOFF2，来源、许可与构建脚本见[字体说明](../public/fonts/README.md)。

本地证据位于 Git 忽略目录 `.local-backend-review/15-login-design/`：browser.mjs、browser.json、明暗/各屏宽/帮助展开截图，以及各检查日志。Vite/API 为本机 4399/4398；浏览器使用独立测试 profile。初次有窗口高度受桌面窗口管理限制的截图，因此最终视觉截图和可视区域断言改用固定视口的无头 Chrome；并按应用实际高度校验，不能只以 innerHeight 推断按钮可见。

## 范围限制

知乎入口仍是当前配置下明确标记的本地演示授权；本次没有验证生产 OAuth，也未重新运行收费模型流程。构建仍报告既有大 chunk 提示；测试环境的无 Canvas 提示不代表真实浏览器绘制失败。以上结果证明本轮登录界面和既有本地身份行为，不证明产品生产部署完成。
