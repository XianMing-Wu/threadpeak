# 作者输入、白色面板与评论修正

> 本文保留上一轮的验收记录。其“数据与推荐设置”入口、评论总数和查看全部评论链接，已按用户后续裁决移除；当前实现与验证以 [视觉与评论更新](visual-atlas-2026-09-07.md) 为准。

## 本轮行为

- 作者搜索的目的选择、问题、学习记录开关、深度和补充背景入口位于同一 Composer。该实例关闭 BeamFrame 的动态边缘；首页等其他实例的动效配置保持独立。
- 补充背景使用共享 FloatingPanel，支持关闭按钮、完成、Escape 与外部点击关闭。三个字段即时写入当前简报，收起保留；未发送前不会提交搜索。面板在浏览器顶层显示，不增加输入框或页面内容高度；空间不足时在视口内摆放。
- 原本不明的网络图标改为可见的“参考学习记录”。含义是将已有作者与资料纳入候选，并在问题同样相关时参考使用和有帮助反馈。服务端 network-first 与适配优先合同不变。
- 数据入口改为“数据与推荐设置”，两项独立说明下载内容及重置范围。菜单使用正常流式布局，清除仍需在确认面板中提交；本轮没有执行重置。
- 共享菜单、资料选中、引用标签、知识卡工具、作者详情和资料管理的浅粉／浅紫背景改为白色。选择继续使用勾选、边框、文字和焦点描边表达；图例、进度及用户显式设置的卡片颜色不作为界面状态背景删除。

## 评论合同与限制

用户提供的知乎搜索合同中，`CommentInfoList` 是精选评论数组，`CommentCount` 是原文评论总数。现有接口没有评论列表分页参数，也没有已提供的全量评论接口。前后端原有映射未截断该数组。

ArticleDetail 与作者资料阅读现在共用 SourceComments：直接展开全部已返回评论、区分原文总数与收录数量、提供“到原文查看全部评论”的真实来源链接。旧来源缺少评论元数据时，使用现有按原文 URL 精确匹配的回查，不覆盖原始文章。空数组不能被解释成原文没有评论，演示与不安全链接不生成外跳入口。

浏览器实际核对了截图所示《【深度学习数学基础 02】矩阵运算与线性映射》：原文总数为 4，现有来源返回 1 条，内容是“这是技术劝退问,连评论都没有啊”。其余 3 条未由当前接口提供，不能伪造或声称已在应用内加载。

## 2026-09-07 验收

- `npm test`：512 项通过，包括评论数组超过十条仍完整显示、总数未知或正文未返回、演示和不安全来源等边界。
- `npm run check` 与 `npm run build` 通过。构建仍报告既有主包超过 500 kB 的体积提示；未进行本轮生产部署。
- 桌面浏览器中作者输入框高度为 189 px，打开／关闭背景浮层不变；边缘 animation 为 none、前后伪元素均为 none。Escape 后焦点返回补充背景按钮，选中菜单为白色。
- 用 [窄屏 QA 页面](../qa/author-surface.html) 中实际 390×700 iframe 视口检查响应式断点。输入框高度 227 px；填写背景、切换目的和学习记录、输入问题后发送按钮启用。页面 scrollWidth 为 390，无横向溢出；背景面板左右边界为 12／378，全部字段与完成按钮可见。
- 窄屏管理面板左右边界为 42／378，两项不重叠。真实学习资料中评论默认可见，原文入口可通过键盘到达；知识卡及选中卡、悬浮工具栏的计算背景均为白色。所检查学习页面控制台没有错误。
- 嵌套验收容器的浏览器日志记录了 `MutationObserver.observe` 参数不是 Node 的初始化错误；源码与本地运行依赖未找到该观察器，独立学习页未出现此错误，具体注入来源未确认。窄屏交互、尺寸与截图验证实际完成，但不把容器日志称为零错误。

这些是当前本地代码与实际浏览器样本的验证结果，不代表知乎全量评论能力已接通，也不代表全部设备或生产性能保证。
