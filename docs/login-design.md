# 登录页视觉规范

范围仅为 AuthLanding，不覆盖学习页、路线画布或全局输入控件。登录与账户语义仍以[产品说明](product.md)为准，真实执行证据见[登录视觉验收](../qa/login-design-2026-09-09.md)。

## 设计方向

面向中文学习者的现代知识产品入口。用户先识别问山，再选择知乎账号或游客。桌面以左侧品牌展示、右侧登录操作构成两栏；球形螺旋是填充展示区的背景，标题与说明在其上层。文字可以遮挡球体，不把动效缩为下方插图。删除展示区左下角的独立标语；标题下整合“学习路线、概念讲解、相关博主”及其作用，说明进入产品后能做什么。

taste-skill 设计取值：DESIGN_VARIANCE=7（重新组织构图与控件比例）、MOTION_INTENSITY=5（一个持续但缓慢的背景动效）、VISUAL_DENSITY=3（两种操作与必要说明）。保留现有三峰标识、品牌紫与用户录屏参考的线球，不新增装饰卡片或无关插画。

参考 OpenDesign 的[设计系统方法](https://open-design.ai/zh/solutions/design-system/)和其 [Linear 风格设计规则](https://open-design.ai/zh/plugins/design-system-linear-app/)：将色彩、字体、间距、动效先定义为相互配合的规则，使用中性色层次与单一强调色。这里借鉴层级与一致性，不复制该插件的字体和整套界面。

## 视觉规则

| 项目 | 规则 |
| --- | --- |
| 浅色 | 白色页面、冷灰展示区、炭黑正文；品牌紫只用于标题强调和焦点 |
| 深色 | 炭黑页面、稍亮的展示区、近白正文和低饱和紫；按角色单独定义颜色 |
| 字体 | 本地 ThreadPeak Login 中文可变字体；标题 450、操作 500、登录标题 550；动态错误缺字回退系统中文字体 |
| 层级 | 展示标题 36–54px、登录标题 28px、操作与说明 14px；窄屏标题 29/24px |
| 构图 | 最大内容宽 1480px，桌面展示与登录约 1.24:1，操作区 320–350px；700px 以下转为上下布局 |
| 面板 | 展示区圆角 28px，窄屏 22px；不为登录再叠加阴影卡片 |
| 按钮 | 同宽同高胶囊形；知乎炭黑实心、游客中性描边，深色模式反转前景/背景；无装饰箭头 |
| 文字说明 | 每个入口下说明能力；游客记录用原生 details 展开绝对定位的说明浮层，不参与左右栏尺寸计算；预留滚动条槽位，展开不改变展示区宽高；授权演示状态来自服务端配置 |
| 球体 | 独立 Canvas 叶子组件、全区背景层、略向右下延展；文字附近渐淡，外侧保留前后明暗；不接收指针 |
| 动效 | 约 30fps 缓慢旋转；页面不可见或用户设置减少动效时停止，组件卸载释放观察器与帧循环 |
| 交互 | 悬停 180ms、按下轻微收缩、清晰焦点环；提交期间两按钮禁用，错误原位显示且可重试 |

颜色与组件尺寸唯一实现位于 [auth-landing.css](../src/pages/auth-landing.css)。字体来源、许可与重建方法见[字体说明](../public/fonts/README.md)。

## 维护检查

修改文案后检查中文子集覆盖；改动球体大小时同时检查桌面与窄屏的文字可读性。窄屏允许纵向滚动，不能横向溢出或让背景拦截按钮。需要核对明暗主题、减少动效、键盘展开帮助、等待/错误状态和两个入口的现有身份隔离行为。
