# 登录页视觉规范

范围仅为 AuthLanding；身份语义仍以[产品说明](product.md)为准。本轮设计与真实参考页面见2026-09-13 登录重设计（本地记录 `../qa/login-redesign-2026-09-13.md`，不随仓库发布）。历史线球方案的证据保留在原记录，本轮以用户要求的产品介绍页风格替代。

## 设计方向

以“想做的事，从这里开始”为入口主张。延续介绍页的白底、蓝色艺术字与细线 SVG，展示从目标到实践、再到必要时寻找真人咨询人选的学习过程。桌面以较宽的插画区配合紧凑登录区；手机先保证两个入口可达。登录页在一个视口内呈现，不设阶段切换条、底部说明或页脚。

参考调研主要借鉴 Whereby 的手绘亲和感、Milanote 的纸张气质、Linear 的入口聚焦，以及 Typeform/Runway 将展示动效与操作区分开的方式。具体来源、当前页面观察及未能访问的登录入口均在当次 QA 记录中列明，不把产品首页或验证拦截页冒充登录参考。

## 视觉与行为

| 项目 | 规则 |
| --- | --- |
| 颜色 | 白底、墨色正文、蓝色强调、少量绿；深色使用独立的蓝灰与浅蓝，不影响全局工作区配色 |
| 品牌 | 保留三峰形状；固定中文标题为本地矢量字形，沿用介绍页 Ma Shan Zheng 来源与许可 |
| 正文 | 本地 ThreadPeak Login 字体；新增文案覆盖 AuthLanding 与 LoginJourney，动态错误允许系统字体回退 |
| 构图 | 内容最大 1200–1320px，视口内分配高度；插画让出空间，两个登录入口始终优先 |
| 控件 | 薄纸张面板、蓝色知乎主按钮、描边游客按钮，清楚的文字和小箭头；避免大胶囊与分离的亮面图标块 |
| 插画 | 原生 SVG、三张语义不同的纸张、清楚的连接路径；只作示意，不建立个人数据或真实作者关系 |
| 动效 | 节点强调约 5.2 秒一段，始终保留完整图形；纸张小幅起伏、纸飞机与路径细微流动，登录控件不跟随漂移 |
| 暂停 | 顶部小图标可暂停；减少动效与页面不可见时停止，卸载释放时间线；无底部播放/章节条 |
| 登录 | 保留知乎与游客真实流程、配置不可用提示、演示标识与服务端会话；等待中禁用重复提交，错误可重试 |
| 帮助 | 原生 details 向上展开浮层，不改变页面与插画尺寸；两入口与键盘焦点保持可达 |

实现位于 [AuthLanding](../src/pages/AuthLanding.tsx)、[LoginJourney](../src/pages/LoginJourney.tsx) 与 [auth-landing.css](../src/pages/auth-landing.css)。本地标题生成脚本为 [generate-login-lettering.py](../scripts/generate-login-lettering.py)，字体来源见[品牌来源](../src/ui/brand/sources.json)与[正文字体说明](../public/fonts/README.md)。

## 维护检查

修改后核对实际宽高下的整个页面，不以 overflow:hidden 掩盖被裁切的按钮。检查桌面、窄屏、矮屏、明暗主题、减少动效、键盘展开帮助、等待与错误状态。动效与展示不得改变身份或学习语义。
