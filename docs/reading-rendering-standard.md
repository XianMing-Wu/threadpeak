# 阅读渲染规范与异常回归

适用：研究中的文章、作者资料阅读、聊天、知识画布、文档阅读。原始 API 摘要、上传正文和用户编辑值分别保存，渲染绝不覆盖原文。用户要求以实际异常建立可回归规范；本文件与 [Agent 显示合同](../agent-specs.md#八公式显示合同本次修复) 配合使用。

## 唯一处理链

`原始来源 → 安全图片与 HTML 处理 → 代码识别和保护 → 数学定界与编码规范化 → Markdown/GFM → KaTeX 或原式降级`

- 共享入口是 `MarkdownMath`；`prepareReading` 返回规范化内容、阅读版本、诊断码。组件不各自用正则替换公式。
- 来源完整性与显示成功是两件事。KaTeX 能显示一些公式，不表示 API 原摘要完整。
- 普通代码围栏、行内代码、链接、路径先保护。只有 `math/tex/latex` 围栏转数学。
- 无围栏代码需要明确编程语法：import、声明、成员调用、内置构造调用、带 `for … in …` 的推导式等。`=`、下划线不能单独作为代码证据。已确定的程序块保留缩进、换行、索引、注释；括号不完整时不能吞掉后面的中文解释。原摘要若本来缺少 in 或多了括号，按代码显示但不擅自纠正其内容。多行前瞻有长度和行数上限。
- 独立一行误包在数学符号中的完整程序，在没有 LaTeX 命令且编程证据充分时转代码。含义不清的混合输入保留可见原式，不猜写程序。
- 正文中的长 snake_case 名称按程序标识保留；短 `x_i`、明确数学定界符中的表达式继续按数学渲染。
- 数学明确使用 `$…$`、`$$…$$`、`\(…\)`、`\[…\]`；裸 LaTeX 只作有界兼容。编码解码在受保护内容之外进行，替换字符串不得将 `$&` 等当 JavaScript 替换指令。
- 等号与紧随矩阵合成一个公式。矩阵内行分隔不等于正文换行。完整等式超宽时允许整个公式容器水平浏览；禁止矩阵内部纵向滚条。代码保留作者真实换行，不能为了“一行公式”强行合并代码。
- 在 GFM 分栏前保护行列式、范数、条件概率、array 列分隔中的竖线，渲染时恢复，不改变表格列数。

## 异常的显示规则

| 情况 | 规范行为 | 不允许的处理 |
| --- | --- | --- |
| 完整数学或可确定的编码/定界修复 | 显示公式，保留原输入 | 根据主题重写数学含义 |
| 未知宏、缺少无法确定的参数、超过限制 | 可见原式，标记 `unresolved-formula` | 空白、静默删除、编造参数 |
| 知乎公式图片含真实 LaTeX | 同一公式处理链 | 当普通图片丢弃 |
| 只有安全图片链接 | 显示原图片；加载失败显示替代文字或明确占位 | 坏图直接消失、猜出图片内容 |
| 空定义、运算律缺项、连续空公式列表 | 顶部说明摘要缺式；原摘要可查看 | 把完整性提示放在长文末尾 |
| 阅读缺式知乎来源 | 持久任务整理独立 AI 公式讲解，明确“非作者原文”；原摘要折叠保留 | 把补充讲解当恢复的博主原文或回写证据 |
| 整理等待、失败或不能访问来源 | 显示状态/继续入口/原文入口 | 定时器假装成功、无限显示旧完成结果 |
| 画布、文档或列表中的缺式来源 | 使用相同诊断与提示；从来源入口阅读全文 | 浏览画布时为所有卡片自动批量生成讲解 |
| 代码被误判为数学 | 依据编程语法恢复代码；逐字符保留操作符和变量 | 将下划线变下标、将 for/range 变斜体数学 |

诊断码：`missing-operands`（缺操作数）、`empty-math-law`（空运算律）、`empty-formula-list`（公式列表缺项）、`unresolved-formula`（无法解析）。前三项表示已观察到的缺失模式，不能用“无诊断”证明任意来源完整。

安全边界：不执行来源 HTML、不开放 KaTeX trust、不共享宏状态；图片协议、地址、公式长度、展开次数有限制。异常只能影响自身内容，不能控制页面布局或执行脚本。

## 缓存与版本

`READING_POLICY_VERSION` 同时用于客户端缓存与服务端任务范围。规范或缺失检测变化时升级；旧“完成但无讲解”记录不能继续遮住新检测结果。同版本、同账号、同 URL、同摘要、同阅读模式幂等；仅头像查询与包含讲解的查询分开。

## 持续验收

- [异常样例数据](../packages/contracts/src/reading-corpus.ts)：30 个最小样例，含用户截图中的列表推导、NumPy、空分隔符和对应正常边界；属于测试资料，不进入生产搜索或学习数据。
- [真实组件回归](../src/lib/math-robustness.test.mjs)：执行共享预处理和 MarkdownMath SSR，核对代码内容、公式数量、来源诊断、表格单元格和原式保留。
- [可视化验收页](../qa/reading-lab.html)：开发服务打开 `/qa/reading-lab.html`，查看同一批样例，可切到 320px 卡片；仅 QA 入口，构建不作为产品页面发布。
- [来源任务回归](../server/durable/source-presentation.test.mjs)：账号隔离、原文 URL 匹配、头像/讲解隔离、版本迁移、原始资料不变、任务幂等。

每次新增缺陷：保存最小原始输入与预期 → 先增加失败用例 → 修改共享处理层 → 检查正常边界 → 在宽/窄实际页面验收 → 涉及解释变化时升级版本。不能以不断追加某篇文章标题特判代替规则，也不能承诺检测未提供数据中的所有语义缺失。
