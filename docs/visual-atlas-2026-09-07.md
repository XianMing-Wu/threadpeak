# 2026-09-07 视觉资产、作者卡片与评论更新

## 本轮用户裁决与实现

- 评论区逐条展示接口返回的全部非空评论。移除原文总数、精选覆盖说明和重复的“查看全部评论”链接；正常文章原文入口保留。空评论区不显示。未改写来源内容，也未添加未返回的评论。
- 移除博主网络的“数据与推荐设置”及其下载、重置面板。作者资料内部的主题偏好仍属于既有次级操作，不参与首页入口。
- 轮播每位作者只展示一篇代表文章。头像、姓名、身份说明、资料数量和文章标题各自预留固定高度，身份与文章至多两行；详情继续列出同一稳定作者 ID 下的全部资料及关联概念。点击当前卡片或按 Enter / 空格可直接打开详情，侧面卡片先居中，拖动后继续抑制误点击。
- 首页正上方改为彩色山脉简笔画：蓝灰远山、青绿主峰、暖黄色太阳和金色上山小径。插画为本地 SVG、无动画、不接受指针事件，标题与输入框保持独立可读。
