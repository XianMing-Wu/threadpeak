# 产品说明：现状、目标与边界

当前用户的明确裁决优先。[Agent 合同](agents.md)拥有提示词、上下文与输出结构，[工程设计](engineering.md)记录运行机制。本文区分已实现行为、产品裁决与未验收事项；旧版报告经[历史索引](history.md)追溯，不作为现行合同。

## 1. 当前实现

| 范围 | 活动实现与边界 |
| --- | --- |
| 介绍入口 | 根地址首先展示独立的产品介绍文档；手动滚动连续跟手，停止后补完到完整状态，导航每点击一次向下推进到下一个完整状态。论文、收藏、纯目标输入与目标聚焦路线均为交互演示，不创建个人资源。顶部“登录问山”和结尾“开始我的学习”进入 `#login`，保留知乎与游客双入口；现有工作区深链接及 OAuth 回调沿用真实身份流程 |
| 路线 | R1 → 两路检索或限定资料 → R2 仅提取待补查的 2–4 个名称（关闭思考，无真实缺口可更少）→ 每载体目录补查与 2–4 题访谈并行 → 两份总结与真实回答直接进入 R4 → 顺序/双载体并列阶段编译 → 3D 校验发布。题目可提前回答，全答且资料就绪自动生成；发布路线不创建知识图 |
| 目标 | goal-v1 保存原始目标、真实回答、成果和概念用途/深度/检验；未知个人条件不编造，资料片段与来源 ID 回查 |
| 学习 | 四项概念总结贯穿2–6项分批搜索、互补资料筛选与连续L-answer教学。文章先可读；正文与关联分检查点，回复和卡片原子提交 |
| 资料 | 首页支持文件、授权收藏和公开创作；全知乎/全网/仅收藏夹范围随路线冻结，所选资料继承到各概念 |
| 工作区 | 研究、画布、文档、聊天共享服务端资源；卡片单父，编辑不覆盖原文。新对话归档旧聊天，保留知识树与文章 |
| 作者 | 问博主2–4项分批搜索，选择1–3位新作者，每位独立卡；有候选至少一位，无直答兜底。博主搜索 network-first 后继续探索证据，最多 3 位；不向作者发送消息 |
| 交互 | 默认快速回答；两档共用 flash，快速关闭思考、深度开启 low，真实思考流以可展开状态条保留。白色面板、浮动提问、文档编辑、来源完整阅读、统一公式/代码处理与缺式提示；路线位置由 renderer 状态恢复，最近学习标记独立 |
| 示例 | 六条流动目标、三个目标故事、23 个概念共用当前学习和 3D 组件；每条路线有并行载体及汇合，前端仅标示例，编辑与个人资源隔离 |
| 恢复 | 单一 durable 服务入口，持久检查点、所有者、幂等、租约与 fence；刷新不取消。旧服务调用与客户端图生成引擎已删除 |
| 浏览器 | 本地只存草稿/偏好/投影与保留的旧记录；路线页和知识页不展示旧版归档。账号切换先持久备份，实际恢复失败时提供紧凑提示与导出 |
| 服务平台 | PostgreSQL/PGlite 同连接 savepoint；单条一致快照、原子事件版本、独立维护与正常停机交回；共享 HTTP 额度及知乎两路额度 |
| 身份 | 知乎账号与游客双入口；游客使用服务端隔离会话及同一持久学习流程，隐藏授权个人资料。真实 OAuth 按官方 `/user` 的 uid 绑定账号，大整数无损解析，支持回调双参数、state/浏览器绑定、加密 Token 与到期重连；可接受信网关。本地 OAuth mock 仅隔离演示，生产拒绝；本地真实授权、刷新恢复和收藏夹列表已验收，范围见 OAuth 账本（本地记录 `../qa/oauth-integration-2026-09-12.md`，不随仓库发布） |

模块职责见[开发指南](development.md)，事务、限速、缓存与保留机制见[工程设计](engineering.md)，阅读异常规则见[阅读规范](reading-rendering-standard.md)。这些描述不能替代第 3 节的具体运行证据。

本轮审查修复：资料恢复失败保留已选 ID 并阻止遗漏资料发送，提供重试与显式移除；此前新 R4 采用严格失败关闭；本次按第 2 节更新为程序容错，reasoning 仍不进入正式业务输出；检索保留有语义的 URL 参数，作者问法校验与发送共用打包规则，深层单父树采用迭代校验与布局。实现与本次验收分别见[修复记录](../qa/project-audit-fixes-2026-09-08.md)。

## 2. 当前产品目标

2026-09-13 路线容错裁决：最终路线生成不因模型 JSON 缺陷向用户返回重试。程序从正式输出提取可用载体与概念，修复字段和结构；并列关系不明确时按输出顺序编译为直线路线。没有可提取内容，或最终 R4 上下文无法准备、模型服务未能给出正文时，依据已保存的用户目标建立最小直线路线，明确保留资料关联的未知项，不伪造书课目录、引文或个人情况。模型结果与程序恢复来源分开记录；取消、所有者、持久事务与外部服务故障仍保持真实状态。思考在首段正式输出到达时自动收起，路线整理继续显示进度，完成后仍可展开阅读。

2026-09-13 介绍页裁决：启动首先打开产品介绍，用户明确点击登录入口后再展示登录页。介绍页延续本地艺术字和连续滚动，导航每点击一次推进一步，读完一段再到下一段；学习卡说明完整、笔记卡讲清自己的理解并保留公式。结尾明确支持仅给出目标开始，不要求上传文件或选择收藏。GitHub 导航指向项目正式仓库。总体理念是从用户的具体想法和目标出发定制学习，只学实现目标所需的部分；学习足迹积累真实卡点与和博主之间的帮助、交流线索，博主网络让问题与相关经验建立联系。当 AI 无法解答具体问题、用户考虑付费请教时，用这些积累辅助判断咨询人选。

2026-09-12 账号展示裁决：游客头像使用刘看山，已登录用户使用服务端返回的本人头像；侧栏和设置共用当前会话，账号切换后同步更新。知乎 OAuth 授权页中的产品图标使用项目原版紫色山形 MountainMark，由知乎应用后台保存。

2026-09-12 作者头像修复：收藏夹回答短链接与搜索返回的长链接按准确回答 ID 匹配；标题检索未命中时补一次带作者名的检索，仍须回查同一原文，不按名字认人。旧空头像缓存随元数据策略更新；头像缺失或坏图显示中性占位及明确提示。真实接口覆盖边界见作者头像验收（本地记录 `../qa/author-avatar-2026-09-12.md`，不随仓库发布）。

2026-09-09 路线与作者审查裁决：3D 尺寸变化时同步重建阴影主贴图、深度与模糊中间贴图，保持亮度，释放资源不改变路线或位置。问博主带入当前对话、所选卡的冻结正文及其真实来源，结合概念四项总结和路线目标理解问题；找人评估使用来源总结、评论、时效、内容指标和对应学习足迹，不能用人气或反馈代替问题适配。作者卡及其网络回读保留实际返回的元数据。请教准备改为可直接粘贴的私聊消息，按钮为“复制私聊内容”：明确来意、自然表达具体问题和期望帮助，不添加用户没有说过的经历或基础；不自动发送。新搜索由同一 N2 生成问题正文，程序补齐真实称呼、材料和咨询/邀请结尾；旧记录兼容且保留已编辑草稿。现场证据见[路线与作者审查](../qa/path-author-audit-2026-09-09.md)。

2026-09-09 登录裁决：登录页明确提供知乎账号登录和游客登录。游客同样可以规划、学习、搜索博主、上传文件并保存进度，区别仅在授权个人资料：游客不请求或显示收藏夹、创作导入、OAuth 连接与授权入口；全知乎和全网公开检索保留。首页与设置依据服务端会话能力展示，服务端也阻止游客提交收藏夹范围或授权资料导入。登录页按 2026-09-13 最新裁决与产品介绍统一：白底、蓝色矢量艺术字、细线学习路径插画及紧凑双入口，替代旧线球与紫色胶囊方案。整个页面在一个视口内呈现；不显示底部阶段切换、补充文案或页脚。支持浅深主题、减少动效和插画暂停，帮助浮层不撑开布局。具体构图与视觉参数见[登录视觉](login-design.md)。正式会话与游客恢复身份分离，退出撤销活动会话，当前浏览器可重新选择游客恢复原记录；游客与知乎工作区不自动合并。

2026-09-09 首页示例裁决：流动建议使用用户给定的六条完整目标；知识脉络和路线统一为 Agent 求职、明代历史、个人理财三组。必须运行真实流程后再人工润色，每条路线合理体现两个并行载体及后续汇合。原稿和编辑记录留在内部，前端不显示润色、制作或投资人说明，仅保留简短示例身份。内容和证据见[示例维护](showcase.md)。

2026-09-09 首次教学与问博主裁决：全链路取消知乎直答。路线每个概念的 learningSummary 是含 focus/boundary/routeConnection/materialConnection 的必填教学总结，description（发布后 detailedDescription）保留短简介，明确当前范围、目标用途、资料对应和前后衔接。首次学习根据这份总结、路线说明和真实目标生成 2–6 条互补搜索项，一项一次搜索、两条一批、前批收齐再发下一批；筛选互补来源后，由刘看山以老师身份生成连续详细讲解，每块 H2 标题、正文及真实来源引用。问博主认真理解所选卡和当前问题，生成 2–4 条搜索项按同样方式执行；有真实候选时至少选择相对最合适的一位、至多三位，每位博主单独一张卡，说明部分适配的边界，不把公开文章说成本人新回复。完全没有可核实候选时只能说明未找到，不能虚构作者或转直答。仅收藏夹沿用用户已冻结的材料范围，不新增外部检索。

本轮首次学习读取所有候选总结，通常保留3–6篇互补文章、最多8篇；用户附件与路线两轮知乎总结不受此上限影响。已选文章和资料直接用于连续教学，没有三角度中间输出，也没有直答窗口及重复容量准备。

路线内容以用户成果为边界：搜索发现目标相关的不同方法和载体，访谈收集决定选择的未知条件，最终先确定必要内容再选择载体局部。用户实际回答、来源建议和模型的 routeEffect 分开解释；模型不得增设成果来证明额外课程必要。方法或课程附带的要求不冒充目标的普遍前置；已有能力不重教，必要前置不因偏好删除。时间主要调整节奏，并列仅用于两个都需学习且相互无依赖的载体。资料、理论、系统认识与作品目标使用各自适合的完成标准。学习阶段继承概念用途和深度；上述语义需要真实输出对照验收，字段合法不足以证明成立。

2026-09-10 模型与状态裁决：首页新任务默认快速回答，不继承浏览器旧的深度偏好。快速回答与深度思考均使用 `deepseek-flash`，快速显式 `thinking.type=disabled` 且不传 reasoning_effort，深度显式 `thinking.type=enabled` 且 `reasoning_effort=low`；R2 短名称提取保留关闭思考的既有例外。 最终路线生成 R4 是快速模式的唯一思考例外：也使用 enabled/low，同一步骤修复保持 low；其他快速步骤仍 disabled。已接受任务沿用冻结档位，成功检查点可复用；后续实际模型调用使用当前参数。真实 `reasoning_content` 通过单独状态条持续呈现，生成时展开、结束后收起并可重开，刷新仍保留；同一步骤只显示最新尝试状态，先前过程在展开记录中保留，重试成功不残留独立失败胶囊；失败/停止本身不得标记思考成功。目录状态识别当前 v7 及历史 v6 检查点，完整全网组收齐才完成。思考内容与正式答案、校验结果和诊断日志分离。

2026-09-09 路线提速裁决：移除完整载体/概念/争议的中间生成，争议转为访谈条件。待补查名称最多四个，一名一查，先两条收齐再查下一批；与访谈出题并行，题目完成即可回答。最终模型使用两轮全部内容总结（仅 summary 换行合并）、题目说明和真实答案，一次选择目标相关的载体与概念；顺序由数组表达，只允许一或两个并列载体，模型不写连接。学习过不等于现在能用，必要前置学到够用，备用资源不全部塞进主线。具体合同见 [Agent 合同](agents.md) 第 1 节。

2026-09-07 连续讲解裁决：访谈第四行直接可编辑；移除划选引用到提问。L-answer 先组织连贯正文，再独立关联引用、编辑卡片；关联重试不能清空或重播正文。阶段状态来自真实任务事件，等待和恢复保留预览，聊天和卡片继续原子发布。渲染规范增加 C/C++ 程序块、未闭合流式公式和暂停/恢复场景。实现与验收记录见 [连续讲解修复](https://github.com/XianMing-Wu/threadpeak/blob/24ce021d896bb355543887f8b6665a3b72d7d16f/docs/continuous-learning-2026-09-07.md)。


本轮 Agent 裁决：从用户最终想完成的成果倒推最小充分路线；论文、收藏、作品、求职和系统学习不能套同一目录。不同作者的建议按目的、基础、成立条件和取舍理解。访谈每题恰好三个建议加自定义输入，选项只帮助表达，原话具有同等效力；已知条件不重复追问。每个概念说明目的、足够的深度和检验任务；有资料时以真实片段说明直接或必要前置关联。最终目标贯穿后续所有学习与作者步骤，原话不可被摘要或作者观点替换。

2026-09-07 展示裁决：示例必须精心编选并逐概念真实搜索知乎，以用户目标及实际材料组织最小必要路线；示例身份清楚，不能成为真实生成失败兜底。示例与“我的知识脉络”使用同一套界面和交互，只重构内容数据，不额外增加专用说明面板或样式。首页建议保留既有流动效果，仅更新内容，并保持滚动到底时山脉与标语的构图。

本轮视觉补充裁决：保留页面灯效；首页输入聚焦时显示原流光边框，普通输入不出现蓝色外选框，作者输入保持静态。Peak 艺术字恢复悬停渐变动效。首页两组推荐复用发现作者的 Coverflow 透视堆叠效果，直接在卡片上提供进入入口，增加展示项，不显示独立翻页按钮、计数或重复说明条；流动建议不显示暂停按钮。品牌区随滚动收起，英文艺术字移到山脉后方，中文标语停留在山脉前方，向上滚动恢复。

路线页最新视觉裁决：按用户知识广场参考图去掉顶部灯光，使用紧凑白底、深色柔和圆体标题与灰色说明。两侧点状路线连接浅色主题标签，辅以书本、清楚的三峰山脊等 SVG 插画；标题两旁补充小指南针与纸飞机，填充中部留白。字号与字距适配窄屏，不增加顶部操作入口。

知识脉络最新视觉裁决：合并为一个书架页，取消我的／示例页签；每条路线为一层，已存在的概念知识为书本，按真实载体和概念顺序排列。每层独立横向滑动，左右都有边界，不重复或循环显示书本。桌面层板收至恰好容纳四本书，小屏按整本数量适配；初始和滑动停止时不露半本，左右滑动以一本书为单位平滑吸附。采用 Three.js 建模开放式金属层板与书本，参考浅灰梯形台面、薄银色前沿、两端亮边和底部柔和投影；取消柜体外框、背板及层板上的标题、编号、数量和箭头。层板距页面两侧留白，书本滑动区域也向内缩，滑动时仍保留层板两端空隙。保留用户认可的书本比例、厚度与已有封面构图，概念名作为主书名、载体名作为上方副标题、路线名作为底部系列名；个人资料与编选示例共同展示，但 ID、打开入口与持久化仍隔离，示例在书封保留短标记。不因同名合并路线，不为尚未学习的个人概念生成假知识。搜索覆盖路线、载体和概念，只筛选书本，各层金属底座与位置始终保留；加载／失败保持真实状态，不能用示例冒充个人读取成功。WebGL 不可用时明确提示并保留普通书架的阅读与滑动入口。此前双页图文列表、闭合柜体及横梁标签裁决已被本次要求替代。

作者页后续视觉裁决：顶部灯效替换为真实公开作者的紧凑竖向卡片，不显示大标题、副标题或来源折叠入口。以 Coverflow 为初始参考，最终按用户圆周示意实现：卡片公转与自转同步，只展示前方圆弧；可见弧内匀速从左向右、由远及近再远去，完全离开视口后加速沿背面返回。相邻卡片保持间隙，中央卡片有透视放大；放大镜固定向右下 45°，中心小范围圆周运动并实际放大镜下内容。顶部仅为编选装饰，不写入搜索结果、作者网络或使用权重；出处保留在 QA 来源账本。减少动效与不可见页面暂停动画。

本轮补充裁决：作者搜索输入框内统一承载请教目的与搜索设置，不使用动态边缘；补充背景为悬浮编辑，不展开输入框。菜单、选中态及阅读／知识工具面板统一白底，不用粉色填充表示选中；用户显式设置的卡片颜色与图例语义独立保留。移除数据与推荐设置入口。评论区仅完整列出 API 返回的非空评论，不展示总数、精选覆盖说明或查看全部评论链接；无返回评论则不显示评论区。作者预览卡固定只展示一篇代表文章，详情保留全部文章。路线及知识脉络封面使用刘看山生成素材；起点、载体、概念、终点的 SVG 标识覆盖示例与真实路线，视觉不更改学习状态。首页正上方绘制带颜色的山脉简笔画，呼应“循着脉络，登上高峰”；输入与工具面板保持白底。

1. 学习页两栏可调宽；研究与知识脉络共享聊天和深度。文章标题、完整 API 总结、作者/点赞/链接只展示真实返回字段，未知字段不补造。
2. 初次进入概念先出现概念名称的用户消息；以四项概念总结、路线说明与原始目标生成2–6条查询，一项一搜，两条一批，前批完成后进入后批。全部收齐再筛选互补资料，由老师生成连续详细的Markdown教学，每块H2标题、正文和引用；文章先可读，失败恢复不丢已有文章。
3. 知识根是概念，一级为文章及本条路线资料，其后为 AI/博主/自定义卡。正交树无限延展；每段一个依据、每卡一个父卡，不再前置/后置/并列或批注。回答工具每次操作只生成一段，并逐段回查引用材料中的证据片段；跨文章内容拆段，不将整篇默认挂在文章 1 下，也不强行轮换引用。路线 3D 可分叉汇合。
4. 选卡决定材料，默认全部文章与路线资料；打开资料详情默认选该文章。AI 快捷项与自由输入均在卡片后长卡；问博主找 1–3 位新作者，有候选至少选相对最适合的一位，每位单独一张卡，无直答兜底。
5. 画布编辑跳到文档对应段落；原始文章与用户副本分开。支持增加同级/子级、配色、描边、分支删除、撤销和重做。
6. 新对话归档旧聊天，当前为空，文章、知识树、编辑与配色保留。切换研究/画布/文档不取消后台任务。
7. 路线为 R1 两路搜索、R2 关闭思考仅提取待补查名称，目录按每名一查且两条一批执行，并行 R3 设计 2–4 道条件题；移除 R2b 完整探索。题目完成即显示和接受答案，全答且目录就绪后 R4 一次读取两份 summary 换行文本、题目说明和全部真实回答。所有载体与概念只服务当前目标，通用学科可补全，具体书课目录缺依据不编造。每题三个建议加独立自定义，主动追问仍最多三轮、旧题保留且不可答。本地上下文配置 500000，输出上限独立。阶段按数组顺序，parallel=false 一个载体、true 恰好两个；程序编译关系、3D 校验、原子发布，不建立知识。已答题默认收成状态条，可展开完整题目和答案，刷新仍保留；安排与发布步骤显示在已答题下方。
8. 请求先持久接收，刷新重连恢复同一任务，自动恢复只做未完成步骤。当前任务继续与用户重新制定是不同动作，后者新建路线。
9. 接收请求时固定深度和引用内容版本。新的深度只影响下一次操作；摘要、修复不得暗中改为快速。
10. 内部错误保持可诊断，但不在用户界面罗列 schema、Agent、JSON 等错误。已有内容可读，暂停可继续，失败不得伪造成功。卡片上的 AI/问博主输入就地显示发送中和提交失败，成功接收才收起；画布也显示等待任务的继续/停止入口。文章详情中的作者身份说明与“查看作者与学习足迹”入口分行呈现。问博主采用本次短编号选择、服务端回查原始证据后发布。

11. 首页艺术字随页面以确定的矢量字形呈现，不依赖外部字体、系统字体回退或网络加载时机。3D 退出不得留下迟到实例，渲染故障支持恢复当前路线，不重新生成学习内容。重新进入时在可交互前统一恢复角色、黄色光圈、导航起点与区域；不重播起点入场。最近一次“开始学习”的概念圆台用紫色标记，普通移动不覆盖该标记，也不改变学习完成。开始学习离开画布前保存该概念为返回位置。

- 作者详情的主流程围绕一篇明确资料与一个明确概念展开；默认展示该作者全部资料，主题偏好不能隐藏其他资料，也不能成为含义不清的全局权重。数学原始资料仍不可覆盖，缺式补充必须与作者原文区分。

2026-09-09 可靠性修正：学习表达的语义要求由当前生成步骤负责，后端不以关键词命中代替理解。格式、数量、长度、引用和图结构仍严格校验；模型修复与临时服务恢复在后台进行，不把常见的表达差异当作用户需要处理的错误。

本轮学习足迹与输入操作裁决：按“资料 → 学习概念 → 参考它整理的讲解/回答的问题”说明来源关系；资料卡与讲解分别显示，同一概念只给一个入口，跳转定位真实卡片。有帮助反馈明确绑定当前资料和具体概念。所有提问输入共用同一发送/停止控件，统一尺寸、图标、颜色、禁用与提交状态；中文输入法确认不触发发送。

## 4. 工程决策与剩余上线工作

### 4.1 已按本次授权选定的工程方案

存储、事务、任务去重/恢复/取消、事件序号和深度冻结点采用 [工程记录](engineering.md) 的方案；它们是本次实现选择，不冒称此前已经由用户逐项裁决。MCP 不作为每个 LLM 的强制包装。

2026-09-06 本轮新增裁决：普通博主搜索入口空白，历史显式恢复；作者 API 身份绑定留在服务端，不向用户展示“身份待确认”。首页资料支持 pdf/md/markdown/txt 和用户明确选中的知乎收藏夹/公开创作。全部本次资料随路线进入各概念的资料列表，按当前概念相关性用于讲解；R4 的 attachmentRefs 表示内容关联，不再控制资料是否可见。文件无知乎作者时不得入作者网络。收藏表示兴趣，不能冒充“有帮助”或主动使用加分。实现与外部阻塞记录见 [资料与知乎账号接入](configuration.md)。

2026-09-06 后续裁决（本轮实施）：首页上传图标左侧增加资料范围菜单，上部“全知乎 / 全网”，分隔线下“仅知乎收藏夹”及收藏夹名称。附件在 Composer 内顶部紧凑显示。范围随路线冻结并继承至概念学习：全知乎沿用站内搜索；全网每路同时涵盖知乎站内和全网 API，两者独立检查点，同组顺序调度控制并发；仅收藏夹不触发外部检索，以明确选中的收藏及上传文件为依据，连续讲解由模型读取资料后直接生成。显式问博主仍使用知乎检索。非知乎搜索证据没有作者网络身份。OAuth 和授权内容域先采用明确标示的本地 mock，与正式接口同合同，生产禁止开启；其他模型、搜索及 PDF 服务仍使用真实 provider。博主结果采用 Coverflow 卡片交互，网络图样式保持。公式图片不能静默隐藏，有明确 LaTeX 时转为公式，否则保留安全的来源图片。

本轮继续修正：旧知乎资料按准确原文 URL 回查头像并持久缓存，不能按作者名猜测。来源缺式时提供标识为 AI 整理的独立阅读版，原始摘要仍可展开，知识卡、引用和权重不变。初始作者目录也使用官方 Coverflow，详情在当前卡片下方显示。示例知识脉络和示例路线进入学习也复用 LearningWorkspace 的画布、文档、研究和对话组件；示例编辑仅保存到当前浏览器标签页，明确标示示例，不提交真实生成任务。作者卡片展示真实昵称、头像、认证图标与认证文案；没有认证时只显示中性的来源描述。详情采用统一字号和固定响应式面板宽度；卡片镜像反射改为右下 45° 投影。

### 4.2 仍需实际验收或外部配置

- 生产 DATABASE_URL、已验证模型窗口和公开源；身份可接可信网关或知乎 OAuth。本轮本地回调已同步知乎后台登记，真实授权经 state 校验、用户信息回查、刷新恢复及公开收藏夹列表读取完成，详见 OAuth 验收（本地记录 `../qa/oauth-integration-2026-09-12.md`，不随仓库发布）。生产 HTTPS 域名登记、正式部署、多设备与完整授权资料导入仍需相应现场验收，本地结果不能代替生产门槛。
- 首页 PDF/MD/Markdown/TXT 已接资料管线；PDF API 文字文档实测通过，扫描件和复杂图表仍需扩充验收。正式内容保留/删除期限、账号删除与备份保留政策仍未确定。
- 任务幂等回执行仍随命令总量增长。无限期拒绝历史命令重放需要保留去重信息；完成任务压缩只减少单行载荷。幂等有效期限、过期命令的拒绝协议、回执归档/删除及容量指标仍是上线门槛，不能直接按日期删回执后接受同一旧命令。
- 大规模不可压缩结构分区、语义检索质量、长对话压缩质量和正式负载/恢复演练。
- 3D 位置以 renderer 不透明场景状态按账号/路线资源 ID 保存到服务端，不用位置推导完成进度；同浏览器移动后重开已核对角色所在载体；跨设备的完整镜头视觉验收仍需补齐。
- 没有官方稳定 authorId 的 API 条目当前使用证据约束的身份后备标识，不按名字合并，收藏返回稳定作者标识时可聚合其多篇文章，相同原文链接可补齐搜索证据的作者绑定；其余跨文章作者身份完备性仍是缺口；这类记录不能因为同名而擅自认定是一个人。

### 4.3 作者搜索与来源网络

作者目标是帮助准备付费咨询或邀请回答，检索公开材料并提供可编辑简报，不代表本人收到提问或已经建立联系。当前合同见 [Agent 合同第 4 节](agents.md#4-搜索博主与学习来源网络)：先读网络，再查新证据；模型选择材料，服务端回查身份和段落，同一作者的多篇材料与多主题关系分别保留。主题反馈影响同相关性排序，清除偏好不删除学习来源。

实现入口为 `server/durable/authors-search.ts`、`authors-network.ts`、`authors-http.ts` 及 `src/learning-v2/Authors.tsx`。当前界面规则以第 2 节和 Agent 合同第 7 节为准。原设计和当时的验证结果保留在[历史版本](https://github.com/XianMing-Wu/threadpeak/blob/24ce021d896bb355543887f8b6665a3b72d7d16f/docs/author-network-design-2026-09-06.md)；不把旧阶段的测试次数写成当前完成状态。稳定作者身份与实际咨询入口的限制见第 4.2 节。

### 4.4 保留与迁移

旧数据库/浏览器数据不直接改成新来源树，不伪造文章来源。旧记录保留用于恢复，不在路线页或知识页列出“旧版内容”、历史对话和常驻导出入口，也不计入当前内容数量；仅实际恢复失败时在页面滚动区域内显示紧凑提示与导出。既有原始记录不因界面修复被删除，新事实只由新的服务端资源写入。根 AGENTS 与 Cursor 规则须引用本版合同。

2026-09-09 阅读与输入补充：求导摘要缺式提示与独立公式讲解覆盖新检测规则，原作者摘要始终保留；Markdown 容器先于裸公式恢复，表格、代码、引用和列表不被公式吞并。全部提问输入的发送/停止按钮统一黑底白图标，禁用态为中性灰。具体规则见[阅读规范](reading-rendering-standard.md)。
