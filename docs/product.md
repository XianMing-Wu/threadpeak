# 产品说明：现状、目标与边界

当前用户的明确裁决优先。[Agent 合同](agents.md)拥有提示词、上下文与输出结构，[工程设计](engineering.md)记录运行机制。本文区分已实现行为、产品裁决与未验收事项；旧版报告经[历史索引](history.md)追溯，不作为现行合同。

## 1. 当前实现

| 范围 | 活动实现与边界 |
| --- | --- |
| 路线 | R1 → 两路检索或限定资料 → R2 → R3/R3b → R4 阶段编译 → 3D 校验发布。当前题组答完自动生成；发布路线不创建知识图 |
| 目标 | goal-v1 保存原始目标、真实回答、成果和概念用途/深度/检验；未知个人条件不编造，资料片段与来源 ID 回查 |
| 学习 | 三种问法、筛选文章、三角度直答与 L-answer。文章先可读；正文与关联分检查点，回复和卡片原子提交 |
| 资料 | 首页支持文件、授权收藏和公开创作；全知乎/全网/仅收藏夹范围随路线冻结，所选资料继承到各概念 |
| 工作区 | 研究、画布、文档、聊天共享服务端资源；卡片单父，编辑不覆盖原文。新对话归档旧聊天，保留知识树与文章 |
| 作者 | 问博主选择 1–3 位新作者；正常零位才由刘看山补充。博主搜索 network-first 后继续探索证据，最多 3 位；不向作者发送消息 |
| 交互 | 白色面板、浮动提问、文档编辑、来源完整阅读、统一公式/代码处理；路线位置由 renderer 状态恢复，最近学习标记独立 |
| 示例 | 五个目标故事、22 个概念共用当前学习和 3D 组件；编选来源与讲解明确区分，示例编辑与个人资源隔离 |
| 恢复 | 单一 durable 服务入口，持久检查点、所有者、幂等、租约与 fence；刷新不取消。旧服务调用与客户端图生成引擎已删除 |
| 浏览器 | 本地只存草稿/偏好/投影与只读旧记录；账号切换先持久备份，离线登录页仍可导出未恢复内容 |
| 服务平台 | PostgreSQL/PGlite 同连接 savepoint；单条一致快照、原子事件版本、独立维护与正常停机交回；共享 HTTP 额度及知乎两路额度 |
| 身份 | 可配置真实知乎 OAuth 或受信网关；显式本地 OAuth mock 仅用于隔离演示，生产拒绝。真实身份仍需正式联调 |

模块职责见[开发指南](development.md)，事务、限速、缓存与保留机制见[工程设计](engineering.md)，阅读异常规则见[阅读规范](reading-rendering-standard.md)。这些描述不能替代第 3 节的具体运行证据。

本轮审查修复：资料恢复失败保留已选 ID 并阻止遗漏资料发送，提供重试与显式移除；新 R4 不再程序补造，reasoning 不进入正式业务输出；检索保留有语义的 URL 参数，作者问法校验与发送共用打包规则，深层单父树采用迭代校验与布局。实现与本次验收分别见[修复记录](../qa/project-audit-fixes-2026-09-08.md)。

## 2. 当前产品目标

2026-09-07 连续讲解裁决：访谈第四行直接可编辑；移除划选引用到提问。L-answer 先组织连贯正文，再独立关联引用、编辑卡片；关联重试不能清空或重播正文。阶段状态来自真实任务事件，等待和恢复保留预览，聊天和卡片继续原子发布。渲染规范增加 C/C++ 程序块、未闭合流式公式和暂停/恢复场景。实现与验收记录见 [连续讲解修复](https://github.com/XianMing-Wu/threadpeak/blob/24ce021d896bb355543887f8b6665a3b72d7d16f/docs/continuous-learning-2026-09-07.md)。


本轮 Agent 裁决：从用户最终想完成的成果倒推最小充分路线；论文、收藏、作品、求职和系统学习不能套同一目录。不同作者的建议按目的、基础、成立条件和取舍理解。访谈每题恰好三个建议加自定义输入，选项只帮助表达，原话具有同等效力；已知条件不重复追问。每个概念说明目的、足够的深度和检验任务；有资料时以真实片段说明直接或必要前置关联。最终目标贯穿后续所有学习与作者步骤，原话不可被摘要或作者观点替换。

2026-09-07 展示裁决：示例必须精心编选并逐概念真实搜索知乎，以用户目标及实际材料组织最小必要路线；示例身份清楚，不能成为真实生成失败兜底。示例与“我的知识脉络”使用同一套界面和交互，只重构内容数据，不额外增加专用说明面板或样式。首页建议保留既有流动效果，仅更新内容，并保持滚动到底时山脉与标语的构图。

本轮视觉补充裁决：保留页面灯效；首页输入聚焦时显示原流光边框，普通输入不出现蓝色外选框，作者输入保持静态。Peak 艺术字恢复悬停渐变动效。首页两组推荐复用发现作者的 Coverflow 透视堆叠效果，直接在卡片上提供进入入口，增加展示项，不显示独立翻页按钮、计数或重复说明条；流动建议不显示暂停按钮。品牌区随滚动收起，英文艺术字移到山脉后方，中文标语停留在山脉前方，向上滚动恢复。

路线页最新视觉裁决：按用户知识广场参考图去掉顶部灯光，使用紧凑白底、深色柔和圆体标题与灰色说明。两侧点状路线连接浅色主题标签，辅以书本、清楚的三峰山脊等 SVG 插画；标题两旁补充小指南针与纸飞机，填充中部留白。字号与字距适配窄屏，不增加顶部操作入口。

知识脉络最新视觉裁决：合并为一个书架页，取消我的／示例页签；每条路线为一层，已存在的概念知识为书本，按真实载体和概念顺序排列。每层独立横向滑动，左右都有边界，不重复或循环显示书本。桌面层板收至恰好容纳四本书，小屏按整本数量适配；初始和滑动停止时不露半本，左右滑动以一本书为单位平滑吸附。采用 Three.js 建模开放式金属层板与书本，参考浅灰梯形台面、薄银色前沿、两端亮边和底部柔和投影；取消柜体外框、背板及层板上的标题、编号、数量和箭头。层板距页面两侧留白，书本滑动区域也向内缩，滑动时仍保留层板两端空隙。保留用户认可的书本比例、厚度与已有封面构图，概念名作为主书名、载体名作为上方副标题、路线名作为底部系列名；个人资料与编选示例共同展示，但 ID、打开入口与持久化仍隔离，示例在书封保留短标记。不因同名合并路线，不为尚未学习的个人概念生成假知识。搜索覆盖路线、载体和概念，只筛选书本，各层金属底座与位置始终保留；加载／失败保持真实状态，不能用示例冒充个人读取成功。WebGL 不可用时明确提示并保留普通书架的阅读与滑动入口。此前双页图文列表、闭合柜体及横梁标签裁决已被本次要求替代。

作者页后续视觉裁决：顶部灯效替换为真实公开作者的紧凑竖向卡片，不显示大标题、副标题或来源折叠入口。以 Coverflow 为初始参考，最终按用户圆周示意实现：卡片公转与自转同步，只展示前方圆弧；可见弧内匀速从左向右、由远及近再远去，完全离开视口后加速沿背面返回。相邻卡片保持间隙，中央卡片有透视放大；放大镜固定向右下 45°，中心小范围圆周运动并实际放大镜下内容。顶部仅为编选装饰，不写入搜索结果、作者网络或使用权重；出处保留在 QA 来源账本。减少动效与不可见页面暂停动画。

本轮补充裁决：作者搜索输入框内统一承载请教目的与搜索设置，不使用动态边缘；补充背景为悬浮编辑，不展开输入框。菜单、选中态及阅读／知识工具面板统一白底，不用粉色填充表示选中；用户显式设置的卡片颜色与图例语义独立保留。移除数据与推荐设置入口。评论区仅完整列出 API 返回的非空评论，不展示总数、精选覆盖说明或查看全部评论链接；无返回评论则不显示评论区。作者预览卡固定只展示一篇代表文章，详情保留全部文章。路线及知识脉络封面使用刘看山生成素材；起点、载体、概念、终点的 SVG 标识覆盖示例与真实路线，视觉不更改学习状态。首页正上方绘制带颜色的山脉简笔画，呼应“循着脉络，登上高峰”；输入与工具面板保持白底。

1. 学习页两栏可调宽；研究与知识脉络共享聊天和深度。文章标题、完整 API 总结、作者/点赞/链接只展示真实返回字段，未知字段不补造。
2. 初次进入概念先出现概念名称的用户消息，三种问法分别搜索，所有知乎接口共用两路并发、第三项排队；收齐后筛选概念相关材料，再执行三个不同角度的直答和最终整理。文章先可读，恢复失败不丢已有文章。
3. 知识根是概念，一级为文章及本条路线资料，其后为 AI/博主/自定义卡。正交树无限延展；每段一个依据、每卡一个父卡，不再前置/后置/并列或批注。回答工具每次操作只生成一段，并逐段回查引用材料中的证据片段；跨文章内容拆段，不将整篇默认挂在文章 1 下，也不强行轮换引用。路线 3D 可分叉汇合。
4. 选卡决定材料，默认全部文章与路线资料；打开资料详情默认选该文章。AI 快捷项与自由输入均在卡片后长卡；问博主找 1–3 位新作者，正常零位由刘看山补充。
5. 画布编辑跳到文档对应段落；原始文章与用户副本分开。支持增加同级/子级、配色、描边、分支删除、撤销和重做。
6. 新对话归档旧聊天，当前为空，文章、知识树、编辑与配色保留。切换研究/画布/文档不取消后台任务。
7. 路线仍为 R1/R-S/R2/R3/R3b/R4，最多三轮亲近访谈，每题三个建议加自定义输入；旧题保留但失效。答完当前题组自动生成阶段数组（如 A → (B,C) → D），程序编译关系后校验、原子发布，不建立知识；每个处理步骤保留明确状态名称。已答题默认收成同款状态条，可展开完整题目和答案，刷新后仍保留。 确认偏好、安排阶段、发布路线等答题后步骤显示在“已选择”下方，包括运行中和恢复历史时。 已答胶囊与前后状态统一行间距。
8. 请求先持久接收，刷新重连恢复同一任务，自动恢复只做未完成步骤。当前任务继续与用户重新制定是不同动作，后者新建路线。
9. 接收请求时固定深度和引用内容版本。新的深度只影响下一次操作；摘要、修复不得暗中改为快速。
10. 内部错误保持可诊断，但不在用户界面罗列 schema、Agent、JSON 等错误。已有内容可读，暂停可继续，失败不得伪造成功。卡片上的 AI/问博主输入就地显示发送中和提交失败，成功接收才收起；画布也显示等待任务的继续/停止入口。文章详情中的作者身份说明与“查看作者与学习足迹”入口分行呈现。问博主采用本次短编号选择、服务端回查原始证据后发布。

11. 首页艺术字随页面以确定的矢量字形呈现，不依赖外部字体、系统字体回退或网络加载时机。3D 退出不得留下迟到实例，渲染故障支持恢复当前路线，不重新生成学习内容。重新进入时在可交互前统一恢复角色、黄色光圈、导航起点与区域；不重播起点入场。最近一次“开始学习”的概念圆台用紫色标记，普通移动不覆盖该标记，也不改变学习完成。开始学习离开画布前保存该概念为返回位置。

- 作者详情的主流程围绕一篇明确资料与一个明确概念展开；默认展示该作者全部资料，主题偏好不能隐藏其他资料，也不能成为含义不清的全局权重。数学原始资料仍不可覆盖，缺式补充必须与作者原文区分。

## 4. 工程决策与剩余上线工作

### 4.1 已按本次授权选定的工程方案

存储、事务、任务去重/恢复/取消、事件序号和深度冻结点采用 [工程记录](engineering.md) 的方案；它们是本次实现选择，不冒称此前已经由用户逐项裁决。MCP 不作为每个 LLM 的强制包装。

2026-09-06 本轮新增裁决：普通博主搜索入口空白，历史显式恢复；作者 API 身份绑定留在服务端，不向用户展示“身份待确认”。首页资料支持 pdf/md/markdown/txt 和用户明确选中的知乎收藏夹/公开创作。全部本次资料随路线进入各概念的资料列表，按当前概念相关性用于讲解；R4 的 attachmentRefs 表示内容关联，不再控制资料是否可见。文件无知乎作者时不得入作者网络。收藏表示兴趣，不能冒充“有帮助”或主动使用加分。实现与外部阻塞记录见 [资料与知乎账号接入](configuration.md)。

2026-09-06 后续裁决（本轮实施）：首页上传图标左侧增加资料范围菜单，上部“全知乎 / 全网”，分隔线下“仅知乎收藏夹”及收藏夹名称。附件在 Composer 内顶部紧凑显示。范围随路线冻结并继承至概念学习：全知乎沿用站内搜索；全网每路同时涵盖知乎站内和全网 API，两者独立检查点，同组顺序调度控制并发；仅收藏夹不触发外部检索，以明确选中的收藏及上传文件为依据，三角度整理用模型读取资料。显式问博主仍使用知乎检索。非知乎搜索证据没有作者网络身份。OAuth 和授权内容域先采用明确标示的本地 mock，与正式接口同合同，生产禁止开启；其他模型、搜索及 PDF 服务仍使用真实 provider。博主结果采用 Coverflow 卡片交互，网络图样式保持。公式图片不能静默隐藏，有明确 LaTeX 时转为公式，否则保留安全的来源图片。

本轮继续修正：旧知乎资料按准确原文 URL 回查头像并持久缓存，不能按作者名猜测。来源缺式时提供标识为 AI 整理的独立阅读版，原始摘要仍可展开，知识卡、引用和权重不变。初始作者目录也使用官方 Coverflow，详情在当前卡片下方显示。示例知识脉络和示例路线进入学习也复用 LearningWorkspace 的画布、文档、研究和对话组件；示例编辑仅保存到当前浏览器标签页，明确标示示例，不提交真实生成任务。作者卡片展示真实昵称、头像、认证图标与认证文案；没有认证时只显示中性的来源描述。详情采用统一字号和固定响应式面板宽度；卡片镜像反射改为右下 45° 投影。

### 4.2 仍需实际验收或外部配置

- 生产 DATABASE_URL、已验证模型窗口和公开源；身份可接可信网关或本轮知乎 OAuth。用户已明确尚未申请知乎凭证，先完成可配置接入。还需补齐官方用户信息接口合同和验证 state 回传；本地隔离会话不能宣称知乎登录完成。
- 首页 PDF/MD/Markdown/TXT 已接资料管线；PDF API 文字文档实测通过，扫描件和复杂图表仍需扩充验收。正式内容保留/删除期限、账号删除与备份保留政策仍未确定。
- 任务幂等回执行仍随命令总量增长。无限期拒绝历史命令重放需要保留去重信息；完成任务压缩只减少单行载荷。幂等有效期限、过期命令的拒绝协议、回执归档/删除及容量指标仍是上线门槛，不能直接按日期删回执后接受同一旧命令。
- 大规模不可压缩结构分区、语义检索质量、长对话压缩质量和正式负载/恢复演练。
- 3D 位置以 renderer 不透明场景状态按账号/路线资源 ID 保存到服务端，不用位置推导完成进度；同浏览器移动后重开已核对角色所在载体；跨设备的完整镜头视觉验收仍需补齐。
- 没有官方稳定 authorId 的 API 条目当前使用证据约束的身份后备标识，不按名字合并，收藏返回稳定作者标识时可聚合其多篇文章，相同原文链接可补齐搜索证据的作者绑定；其余跨文章作者身份完备性仍是缺口；这类记录不能因为同名而擅自认定是一个人。

### 4.3 作者搜索与来源网络

作者目标是帮助准备付费咨询或邀请回答，检索公开材料并提供可编辑简报，不代表本人收到提问或已经建立联系。当前合同见 [Agent 合同第 4 节](agents.md#4-搜索博主与学习来源网络)：先读网络，再查新证据；模型选择材料，服务端回查身份和段落，同一作者的多篇材料与多主题关系分别保留。主题反馈影响同相关性排序，清除偏好不删除学习来源。

实现入口为 `server/durable/authors-search.ts`、`authors-network.ts`、`authors-http.ts` 及 `src/learning-v2/Authors.tsx`。当前界面规则以第 2 节和 Agent 合同第 7 节为准。原设计和当时的验证结果保留在[历史版本](https://github.com/XianMing-Wu/threadpeak/blob/24ce021d896bb355543887f8b6665a3b72d7d16f/docs/author-network-design-2026-09-06.md)；不把旧阶段的测试次数写成当前完成状态。稳定作者身份与实际咨询入口的限制见第 4.2 节。

### 4.4 保留与迁移

旧数据库/浏览器数据不直接改成新来源树，不伪造文章来源。旧记录可以只读归档，新事实只由新的服务端资源写入。根 AGENTS 与 Cursor 规则须引用本版合同。
