# 搜索范围、公式与博主卡片：本次实现及验收

日期：2026-09-06。范围以本轮用户要求为准：修改当前 ThreadPeak 应用，采用本地 OAuth/授权内容 mock，其余模型、搜索、直答与 PDF 仍使用真实服务。本文记录本次检查，不代表生产上线或任意外部调用零故障。

## 1. 用户可见的变化

- 首页 Composer 在原有附件图标左侧增加范围图标。菜单上部是“全知乎 / 全网”，分隔线下是“仅知乎收藏夹”和该账号的收藏夹名称；可选择多个收藏夹。
- 文件使用原有附件按钮上传，在输入框内部顶部显示紧凑文件行，可预览、移除、重试。取消选择收藏夹或切换至其他范围会移除相应收藏选择，保留用户上传的文件。
- 范围和资料在创建路线时固定，并传到每个概念。仅收藏夹以明确选中的收藏和文件制定路线、讲解概念；不会隐式改成外部搜索。用户主动“问博主”仍执行知乎找人流程。
- 博主搜索结果参考 [Coverflow 的交互](https://coverflow.ashishgogula.in/docs)，实现有透视的卡片切换、拖动、侧卡点击、左右键/Home/End 和减少动效。作者网络的原有图谱样式保留。
- 新收到的知乎证据使用实际作者头像、认证、点赞和更新时间；没有返回的字段不编造。历史记录按准确原文 URL 回查头像，独立持久缓存；不按姓名猜测或改写历史身份。

## 2. 范围合同和搜索来源

共享合同位于 `packages/contracts/src/search-scope.ts`。默认是 `zhihu`，另外两个值为 `web`、带 `folderIds` 的 `collections`。服务端校验收藏夹归属、对应资料的完成状态和选择范围，客户端不能仅提交一个收藏夹编号就读取其他账号的资料。

| 范围 | 路线与首次概念学习的材料 | 作者网络 |
| --- | --- | --- |
| 全知乎 | 知乎站内搜索及本路线上传资料 | 只有有实际知乎身份依据的来源参与 |
| 全网 | 每种问法调用知乎站内搜索，再调用全网搜索；独立检查点，恢复时不重跑已完成部分 | 全网结果不产生作者身份；知乎站内结果可参与 |
| 仅知乎收藏夹 | 选中收藏夹的导入资料及本路线文件；不调用外部搜索或外部直答 | 授权知乎内容可保留作者关系；演示身份隔离在演示网络 |

全网 API 按用户提供文档接入 `GET /api/v1/content/global_search`，使用 `Count=20`、`SearchDB=all`。站内搜索 `Count=10`。不虚构分页、无限召回或“已找到全部文章”。去重保留原文与 UTM 溯源地址，同 URL 优先采用能提供身份依据的知乎站内证据。CSDN 等全网材料只保留来源网站、标题、内容与链接；即使全网返回知乎 URL，也不据此猜测作者。

| 知乎返回字段 | 本次使用方式 |
| --- | --- |
| AuthorAvatar | 资料、作者结果、作者详情和来源卡片的真实头像；加载失败时可读占位 |
| AuthorBadge / AuthorBadgeText | 作者认证图标和认证文字 |
| VoteUpCount / CommentCount / EditTime | 点赞、评论数、更新时间；资料可按点赞和更新时间排序 |
| CommentInfoList | 详情中的精选评论，可辅助模型识别争议 |
| ContentType / ContentID / AuthorityLevel / RankingScore | 保存至证据元数据，帮助模型判断类型、时效和相关性；不能用平台分数替代内容正确性 |
| Url | 原始溯源链接，不拼造作者联系方式或咨询服务状态 |

## 3. 公式修复及无法凭渲染器修复的情况

此次查到两类独立问题：此前 Markdown 渲染直接丢弃图片；另一些知乎搜索摘要在返回时已经缺失了公式内容。

统一预处理现在处理 Markdown/HTML 公式图片、可解析的 LaTeX 属性/地址、常见转义及漏定界符、矩阵环境和裸 `qquad` 等格式残留。图片带有明确公式源码时转换为 KaTeX；只有图片地址时保留允许的来源图片；图片失败显示可读反馈。代码、链接、金额和普通图片不会被当成公式盲目重写。

同一行内等式与矩阵放在一个不可拆的公式容器；不再在等号后因为矩阵环境强制换行，也不再产生公式内部的纵向滚动条。独立超宽公式可横向阅读。生成回答的提示词要求完整 LaTeX 定界符、标准矩阵环境和正确 JSON 转义；编辑保留源码。

用户截图对应的“矩阵基础知识点总结 - 知乎”，本次实际搜索返回成功，但该条 `ContentText` 中没有图片标签、LaTeX 反斜杠或 `$`，正文已是“即使 和 都有意义”等缺项句子。渲染器没有可以还原的原式。此前该类摘要只能给出缺式提示。本轮在原始摘要之外新增独立的 AI 公式整理阅读版，明确标示“依据摘要主题补充讲解，非博主原文”；原始摘要仍可展开，原文链接保留，不能把整理结果冒称还原的原式。该检测是保守提示，不承诺识别所有上游内容缺失。

## 4. OAuth 与收藏演示的切换

本地 `.env` 使用 `ZHIHU_OAUTH_MODE=mock`；页面标识演示账号和演示资料。模拟范围仅包含授权、用户信息、公开创作、最近收藏、收藏夹及其内容。前端使用相同授权回调和资料接口，用户 API 的字段、分页和错误边界与真实适配器一致。

演示授权码一次性、与发起浏览器绑定；令牌和身份在服务端隔离。演示 Token 不发送到知乎，演示来源不推荐为真实咨询人选。正式环境拒绝启用 mock；真实模式服务失败也不自动回退演示数据。

获批后的步骤：

1. 将 `ZHIHU_OAUTH_MODE` 改为 `real`。
2. 配置 `ZHIHU_OAUTH_APP_ID`、`ZHIHU_OAUTH_APP_KEY`、`ZHIHU_OAUTH_REDIRECT_URI`、`THREADPEAK_TOKEN_SECRET`。
3. 根据官方用户信息合同配置 `ZHIHU_OAUTH_USERINFO_URL`、稳定用户 ID 字段路径；名称和头像字段按实际响应映射。
4. 重启 API，联调官方授权、回调 state、令牌过期和用户信息映射。

前端和收藏导入接口不用重写。真实凭证及用户信息合同尚未获得，因此本次验证的是可切换架构及本地演示流程，不能声称已经完成真实知乎登录验收。
