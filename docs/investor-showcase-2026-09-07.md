# 投资人展示内容：循着自己的目标学习

本轮替换首页建议、全部五条示例路线及五组示例知识脉络，共 22 个概念。目标是用可以点开核对的内容说明产品价值：先理解用户想完成什么，再组织足够的知识；作者意见与用户目标不一致时，解释适用条件，不用高赞或认证替用户决定。

## 五个故事

| 示例 | 明确的起点 | 可检查的成果 | 为什么是这条路线 |
| --- | --- | --- | --- |
| 读懂 Attention 的两条公式 | 会 Python 和基本矩阵乘法，卡在论文 §3.2 | 标注 Q/K/V 形状，手算单头 Attention，解释多头公式 | 五个概念直接服务指定段落，不先铺完整数学课程 |
| 做一个能拖动旋转的 3D 作品 | 会基础 JavaScript，希望用现成库做出作品 | 拖动、缩放、窗口变化后不拉伸的彩色立方体 | 四个概念沿场景、网格、变换、控制器展开；不把图形学全课程设成前置 |
| 把四篇 NumPy 收藏学成一次分析 | 会列表与循环，有四篇公开资料组成的示例选集 | 用同一张成绩表得到可复算、能解释样本范围的统计结果 | 合并重复 axis 定义，保留清洗、广播和聚合各自用途 |
| 建立自己的家庭理财判断框架 | 希望形成判断方法，收入和风险偏好未知 | 预算、用钱时间表、带条款出处的产品清单 | 先区分资金用途与条件，不套用作者的配置比例或荐买结论 |
| 用一个可靠的文档助手展示求职能力 | 有 Python 后端经验，目标是应用开发岗位 | 有引用、受控工具、评测与启动说明的作品 | 复用已有技能；证据检索和工具边界并行，最后汇入评测与交付 |

每个故事的数据包含一道完整的访谈记录：三个有实际区别的建议，以及“用自己的话说”的回答。目标与已知基础放进现有概念卡、对话和目标上下文；不增加示例专用的访谈面板。

## 内容如何连起来

- 首页五条流动建议用用户语言描述困境，点击只填写输入框、聚焦，用户可以修改后发送。保留原有循环流动、悬停和键盘聚焦暂停；不改变山脉、艺术字或封面素材。收回新文案增加的底部留白，使常用较矮窗口滚到底时标语仍落在山脚附近。
- 首页“查看全部”直达示例标签。五条路线与 22 个示例概念使用同一份内容目录，没有独立的旧版首答。示例知识列表和“我的知识脉络”一样直接列出概念，点击进入当前学习组件，返回同一列表；不额外插入路线介绍页。
- 每个概念有用途、足够的深度、完成检验、三段讲解、一条具体追问与回答，以及回到最终成果的检查卡。共 110 段编选学习内容，不把换句话说算成新概念。
- 论文的阅读锚点始终随五个概念进入；知识树从论文或对应知乎来源延展，讲解引用可回到论文。NumPy 四篇资料在每个概念的研究页都可见，当前概念标明对应来源片段。
- 每个段落只有一个父卡。路线允许并行汇合；求职路线显示两条分支，知识树没有合并父卡。
- 知乎文章保留接口原始摘要、标题、URL、作者、头像及实际返回的认证、点赞和评论。沿用现有来源阅读组件的正文、提示行与原摘要折叠，编选内容解释选它的原因及不采用哪些结论。没有新增示例专用资料卡样式。来源缺式不冒充作者公式恢复；编选讲解中的公式独立核对。

## 真实搜索与编选过程

实际调用知乎搜索接口完成 24 个查询，返回 120 条候选记录（记录数，不是去重文章数）。逐条审阅搜索摘要，显式挑选 22 篇，覆盖每个概念；不是按照返回顺序、点赞或认证自动取第一篇。两组宽泛理财结果没有直接入选，补查历史回撤后再决定范围。

[查询清单](../qa/showcase-2026-09-07/search-inventory.json)记录每次查询的返回类型、时间、候选数和响应哈希。[逐概念编选账本](../qa/showcase-2026-09-07/source-review.json)保存候选标题、原链接、选择理由、排除理由以及入选摘要哈希。运行脚本只打包已审阅的选择，不重新排名。未经编选的整批响应留在本地忽略目录，生产页面不会读取它们。

审阅范围是 API 返回的摘要和下列官方参考，不声称逐篇读完知乎原文全文。部分摘要已经省去公式，这个事实也保留在来源卡中。

| 易误导的地方 | 本轮处理 | 校核参考 |
| --- | --- | --- |
| Attention 缩放被说成必然稳定、保持均匀权重 | 补齐独立、零均值和单位方差假设，区分计算定义与设计动机 | [原论文 §3.2](https://arxiv.org/html/1706.03762v7#S3.SS2) |
| Three.js 核心和附加控制器来自不兼容版本 | 采用同一项目中的模块导入；先以不依赖灯光的材质验证几何 | [Three.js 安装与 addons](https://threejs.org/manual/en/installation.html) |
| NumPy 把 axis=1 注释成垂直汇总 | 以固定成绩表预测并运行输出，解释被规约的轴 | [NumPy 广播规范](https://numpy.org/doc/stable/user/basics.broadcasting.html) |
| 应急储备月数被当作统一要求 | 从收入波动、责任、用途和可获得性讨论，数字只作练习 | [CFPB 应急资金指南](https://www.consumerfinance.gov/an-essential-guide-to-building-an-emergency-fund/) |
| 历史回撤小就不会大亏、宣传词等于保证 | 区分观察区间与未来风险，回查产品条款和费用 | [FINRA 风险基础](https://www.finra.org/investors/investing/investing-basics/risk)、[Investor.gov 投资产品](https://www.investor.gov/introduction-investing/investing-basics/investment-products) |

## 演示顺序建议

1. 从首页“想读懂一篇论文，却卡在公式”说明入口以真实困境为起点，展示可改写的输入。
2. 打开论文知识脉络，沿现有概念卡与对话阅读目标、基础和所需深度：为什么是这五个概念，为什么此时不学完整模型。
3. 进入平方根概念，在研究页查看真实知乎来源和选择限制；在知识树/文档查看完整公式与“训练后的 Q、K 不独立怎么办”的追问。
4. 换到 NumPy 选集，说明四篇内容如何用同一个数据集连接、如何合并重复知识，以及 CSV 导入为何尚不属于本例。
5. 最后打开求职 3D 路线，展示并行分支、阶段汇合与可复验的交付终点。

## 边界与维护

这些是明确标识的编选示例，情境、对话和讲解为展示设计，不是实时 Agent 生成、真实用户历史、上传论文解析或用户授权收藏夹。真实来源不表示作者参与制作或认可本产品。示例不创建作者网络权重、付费服务状态或真实任务。

示例和“我的知识脉络”使用同一套列表、概念卡、`LearningWorkspace` 与阅读组件，不新增说明面板或专用主题样式；可以在独立、带内容版本的 sessionStorage 中编辑与切换对话；原始文章来源不变。新对话保留资料、知识树和目标。问 AI/博主仍引导开始自己的学习，不用固定回复模拟成功。真实生成管线不会在缺配置或失败时回退到这些内容。

维护入口是 `src/showcase/content.ts`、`sources.json` 和 `catalog.ts`。修改内容后更新内容版本，复查来源依据与公式/代码，并运行全量测试和浏览器验收。固定示例通过不等于真实 Agent 在任意目标或任意材料下都能达到同等质量；本次验收范围见[记录](../qa/showcase-2026-09-07/README.md)。
