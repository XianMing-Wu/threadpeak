# 作者资料、学习去向与公式阅读修正

日期：2026-09-06。适用当前本地实现；不是生产上线声明。

## 研究依据与采用方式

本轮阅读了以下产品的官方功能与交互说明。采用的是任务组织方式，并沿用问山现有的白底、淡紫色、细边线和字号体系。

| 官方来源 | 可借鉴的交互 | 本项目落点 |
| --- | --- | --- |
| [Readwise Reader：组织内容](https://docs.readwise.io/reader/docs/organizing-content) 与 [导航](https://docs.readwise.io/reader/docs/faqs/navigation) | 阅读是中心任务，文档操作与辅助面板有各自上下文 | 作者资料列表和单篇阅读分开；正文独立滚动，原文及学习操作固定在页脚 |
| [Are.na：Connections](https://help.are.na/docs/getting-started/connections) 与 [Blocks](https://help.are.na/docs/getting-started/blocks) | 连接的是一份具体内容，随后明确选择归属；内容可以拥有多个连接 | 先打开某篇资料，再“用于学习”，显示这篇资料及目标概念。不会把作者当作待导入的文章 |
| [Capacities：产品](https://capacities.io/product) | 人物和其他对象通过关联内容组织上下文 | 作者下保留全部资料，学习足迹分别呈现文章关联的主题、问题和知识卡 |

## 作者详情

1. 默认进入“作者资料”，显示实际头像、认证信息和全部已发现资料。不会自动打开第一篇全文，也不会由默认主题过滤掉其他文章。
2. 点开一篇资料进入“阅读资料”，正文以稳定字号阅读。原文和“用于学习”在固定底栏；资料的学习关联收在可展开区域。
3. “用于学习”打开独立去向页：顶部标明资料标题和作者，中部列出实际学习概念及所属路线，底部说明选中了哪个概念。占位提示不是可选项。
4. 有有效当前学习上下文时预选它；只有一个实际概念时预选该概念；存在多个概念且没有上下文时不任意代选。
5. 导入仍提交明确的作者、证据及目标概念 ID。服务端先验证归属和相关性，只加入选定的一篇；重复加入显示已有，处理中保留任务进度，失败可继续。
6. “学习足迹”查看各资料的真实关联和主题内有帮助反馈。“推荐设置”独立展示按主题的两个选项：相关时优先推荐；暂停该主题推荐。两者解释实际影响，暂停期间禁用优先开关。
7. 同一作者关联多篇文章、多个主题、多个问题及知识卡的关系保持，作者网络图及 Coverflow 不改动。

## 公式与代码问题的原因

- 截图里的《线性代数系列 Day 03》原始 API 摘要含“设 ，，则”“满足结合律： 满足分配律：”等缺项，之前仅识别两种旧句式，漏掉了这类来源。现在识别空定义、空运算律及连续空列表，排除完整公式、代码、图片和链接。
- 历史缓存只有头像结果时，不代表公式阅读已完成。头像请求和阅读请求分开缓存，版本升级；可见阅读不会在整个作者目录的头像队列之后等待。任务未成功时明确显示等待或继续入口。
- 缺式内容单独生成并标为“AI 公式讲解 / 根据摘要主题整理，非作者原文”，原摘要可展开查看，原始文章来源和卡片不被替换。无法从已被 API 删除的内容恢复作者的具体示例，不声称恢复了原文。
- 《矩阵相关问题》的 NumPy 示例没有代码围栏，旧预处理把 `A = np.array(...)`、`C = A + B` 当作数学。现在先识别明确的程序块，保留多行数组、缩进、注释、赋值和输出语句，再做数学识别。
- 在真实补充讲解里发现 Markdown 表格会把行列式竖线当作分栏符。现在解析前保护数学竖线，渲染时恢复，涵盖行列式、范数、条件概率和带列分隔线的数组。

## 作者足迹对齐

文章底部原本是右侧绝对定位按钮，无法随左侧头像与行高对齐。现在作者信息、赞同和作者足迹处于同一个 flex 页脚，两侧均为 24px 行高并垂直居中。移除依赖子元素位置的旧隐藏规则，长名称省略显示并保留完整提示；窄屏保留赞同和足迹入口。头像加载失败记录按 URL 隔离，换成新地址后可以重新显示。

## 本轮验证

- 实际浏览器打开截图中的《线性代数系列 Day 03》：真实模型完成公式阅读，正文与表格公式可见；公式内部没有纵向滚动区域，保留原摘要。
- 实际浏览器打开《矩阵相关问题》：三个完整 NumPy 代码块保留赋值、数组缩进和输出，代码中没有误渲染的 KaTeX。
- 实际完成一次已有文章的“用于学习”：明确返回已存在，提供“去学习”，未重复添加文章。
- 390px 视口下作者面板宽 366px、无横向溢出；去向页的操作按钮位于可见页脚。推荐开关被旧 checkbox 规则压缩的问题在视觉验收中发现并修正为 34×20px。
- 390px 视口下检查当前 20 张学习资料卡：作者信息与足迹的中心线偏差均为 0，左右行高均为 24px。另检查正常桌面宽度及恢复视口。
- 新增实际 MarkdownMath SSR 回归：空定义、空运算律、完整语句误判、NumPy 多行代码、矩阵表格竖线。新增作者默认概览跨主题展示多文章的 SSR 回归，以及同作者第二篇文章只进入所选概念的服务端集成回归。

- 最终命令：`npm run check` 通过；`npm test` 478/478 通过；`npm run build` 通过。构建仍有既有大分包提示，本轮未将其描述为性能达标。

真实 OAuth 仍使用用户授权的本地 mock；模型与知乎搜索使用已配置的真实 provider。此轮不代表所有上游摘要完整，也不代表外部服务永不失败。
