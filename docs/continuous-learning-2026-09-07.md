# 连续讲解修复 · 2026-09-07

## 现场根因

真实追问任务约 53 秒，连续三次因依据片段不属于指定材料而未通过校验。前两次同一错误重复，最后一次换了段落但仍改写了引文。旧实现将正文、引文和挂卡放在同一模型 JSON 中；每次修复重播整篇，空前缀又覆盖已显示草稿。进入 waiting 时前端只显示 busy 草稿，造成空白。最初学习还遇到一次检索故障与 HTTP 429，不能将所有等待归因于界面。

参考视频的可见特点是正文在后续编辑动作期间仍保留，编辑节点作为独立状态显示。不能由录屏推断其后端实现。

## 修复边界

同一 L-answer 分为正文和关联两个持久检查点，保持单父树、实际材料回查、真实 provider 和原子提交。引文改为服务端材料片段编号，关联阶段不复制易被改写的原句，也不重写正文。保留草稿、真实阶段事件、恢复检查点、取消栅栏；不降低引文归属校验。

UI 仅修复指定交互：直接编辑自定义选项、删除划选提问入口、统一代码和公式流式阅读。已有首页、示例、3D 样式不变。
