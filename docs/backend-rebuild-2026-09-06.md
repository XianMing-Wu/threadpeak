# 后端重构执行记录（2026-09-06）

状态：本轮重构与本地集成验收已完成；公网部署和正式用户规模验收未完成。本文件记录本次工程选择和验证证据，不把设计写成上线事实。

## 本次授权与产品边界

用户已基本接受 ux-ui，要求按新版前端重构主项目后端、提示词、记忆和压缩。此前仅修改 ux-ui 的限制属于预览阶段。最新对话中的卡片树、新对话、问 AI/问博主裁决覆盖旧文档中的批注、G1/G2 和固定首轮展示规则。

- 首次学习：概念名称作为用户消息；拆成三个紧扣概念的问法，并行搜索三次；收齐并去重、筛掉离题材料后展示文章；再执行三种角度的知乎直答，最后汇总。不能声称穷尽知乎全部文章。
- 概念是根，文章为子卡。回答每个段落只有一个依据卡、一个父卡；多选产生独立分支。未选默认全部文章。问博主重新找 1–3 位作者，零合适候选才由刘看山直答；结果成为卡片，不能冒充作者亲自回复。
- 画布、文档、聊天共用服务端事实；文章原始总结与用户编辑副本分开。新对话归档旧聊天、清空当前消息，保留文章与树。
- 路线仍为 R1 → 搜索 → R2 → R3/R3b（最多三轮）→ R4 阶段计划 → 确定性编译 → 3D 校验发布；路线分叉汇合不受知识树单父限制。

## 已观察到的根因

基线代码中运行、题组、首轮、图和作者网络在进程内 Map 中。读取/阶段推进与发布缺少统一持久事务。LLM 流读取会在异常后返回已收到的部分内容；正文为空时可能用 reasoning 代替正文。上下文预算固定 500k，末端存在对序列化 JSON 的字符切片，摘要器失败也使用原文前缀代替摘要。当前基线 340 项测试通过，但 TypeScript 检查存在 11 项错误；这说明测试覆盖与可运行产品并不等价。

参考视频 `相对完整的视频.mov` 长约 722 秒，抽帧观察到搜索占位、持续可读的右侧对话、画布/文档切换和局部新增卡。录屏只能证明可见交互，不能证明参考系统从不发生服务故障。

## 架构选择

1. 保留 Fastify、TypeScript、DeepSeek、知乎 provider；采用 PostgreSQL 兼容持久库，本地使用已有 PGlite。任务、步骤检查点、资源版本、事件与发布写入同一存储边界。生产使用 PostgreSQL。
2. 固定工作流由程序选择下一步骤。工具只有受约束的搜索、直答、结构化生成能力；输入/输出由 schema 校验，引用 ID 回查服务端。模型不直接修改数据库或挑选任意工具。
3. 请求先持久接收，后台执行；浏览器断连不取消任务。任务租约带 fencing token，恢复只重做尚未持久完成的步骤。外部读取/生成可能至少执行一次，业务提交至多一次；不声称外部调用 exactly-once。
4. 自动恢复限流、网络与临时服务错误；鉴权/配置错误进入可诊断的等待处理状态。保留输入、已完成步骤和已有内容，用户恢复任务不会重复落卡。停止与提交竞争由事务裁决，迟到结果不可写入。
5. 回复正文、卡片和最终成功事件原子发布。流式草稿属于临时展示，未验证的 JSON/半截正文不能作为成功结果。题组一次完整提交，刷新后按稳定题组及选项 ID 恢复。
6. 预算取业务上限与实际 provider 上下文能力的较小值，预留真实输出额度及安全余量。原文持久保留；只压缩调用副本。分块摘要保留来源，失败恢复，禁止用截断充当摘要。记忆分为任务检查点、当前对话和跨对话文章/知识树；新对话不偷带旧聊天。
7. 深度在每次任务接收时冻结；之后切换只影响下一任务。结构修复不偷偷降为快速模式。日志记录阶段、时延、错误类别和引用数量，不记录密钥、原始思考或用户全文。
8. MCP 作为将来开放外部工具的可选适配层，不包裹每个内部函数。`read_card_scope` 把当前引用映射到 C1/C2，`append_cards` 只允许每段一个范围内父卡；编号由服务端解析，ID 和事务不交给模型。此次不引入总控模型或语义 judge。
9. R4 仅写 `stages`，外层顺序/内层并列；程序生成所有关系。结构校验和 3D 校验仍保留，同一 Agent 自我修复。状态条从所有持久检查点恢复，完成后保留步骤含义。
10. 公式采用共享规范化、KaTeX 严格尝试和有限格式修复；生成回答先校验再提交，导入文章只修显示副本。文档阅读与纯文本编辑分离。缺失数学信息不猜补，未知宏保留原式。

## 剩余上线门槛

- 用户正式域名/服务器、真实身份签发与回调、证书和登录过期/多设备体验尚未接入。验收中的 localhost HTTPS 与自签测试身份不能替代它们。
- 正式并发量、p50/p95、成本配额/告警、长文本摘要质量与作者检索质量需建立数据集和负载目标后验收；现有耗时只代表几个样本。
- 当前 network-first 使用中文分词关键词匹配，不是已经完成的语义 GraphRAG。无官方 authorId 时的跨文章身份不能据显示名猜合并。
- 附件/会话/备份的保留、账号删除与旧数据迁移政策未确定；大规模不可压缩结构尚需分区。
- 外部服务仍可能限流、断开或截断。产品要保存内容、自动恢复并避免重复落结果，不能宣称零失误。数学信息本身缺失时保留原式，不虚构公式。

## 2026-09-06 前端稳定性补检

本次按用户补充修复首页品牌字形、已答选择题和 3D 偶发黑屏；不是一次新的 Agent 编排改版。

- **品牌**：前轮为兼容 CSP 删除了外部字体请求，却保留了依赖字体的品牌 DOM，导致系统回退字体。现在把原定 Splash、Cormorant Garamond Italic 500、Ma Shan Zheng 的固定文字转成 SVG 轮廓，随组件编译；不存在等待字体或字体加载失败后的普通字形。上游固定 commit、文件摘要和 SIL OFL 在 `src/ui/brand`，手动生成器在 `scripts/generate-brand-outlines.py`。来源：[Google Fonts](https://github.com/google/fonts)、[Ma Shan Zheng](https://github.com/googlefonts/mashanzheng)。正文和公式字体独立。
- **选择题**：提交被服务端确认后使用与流程步骤共用的胶囊样式，默认收起，鼠标/Enter 展开完整问题和所选答案；失效题显示“问题已更新”，不能重新作答。服务器保存完整题组，界面展开状态不改变 Agent 输入。
- **3D 循环根因**：`readWorkspace()` 每次 JSON.parse 产生新对象，宿主 effect 用引用不等判断“修复了文档”，回写后又触发 workspace tick。快速导航测试实际出现 Maximum update depth exceeded。现在持久化入口比较内容，无变化不回写、不发事件。
- **3D 异步挂载**：读取进度有可取消信号，退出后不会继续启动 renderer；每次挂载拥有独立 DOM 和实例租约，迟到完成只能销毁自己。加载提示改为同一个 React 树的 portal，消除同步卸载嵌套 root 的竞争警告。
- **显卡恢复**：连续完整挂载 18 次复现浏览器活跃 WebGL 上下文超限；vendor 仅 dispose 场景对象，未显式释放上下文。最终修复已下沉至上游 LearningScene：销毁 renderer 后释放 WebGL 上下文，重测 18 次完整进出无该警告。主动注入 WebGL context loss 后，原实例恢复曾产生失效 GPU 对象删除警告。现在最多自动重建一次完整场景并读取该路线的不透明进度；持续不可用时提供就地重开，不刷新整页或重生成路线。资源生命周期依据 [Three.js 清理说明](https://threejs.org/manual/en/how-to-dispose-of-objects.html) 和 [WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)；本次从上游源码经 build:module 整份同步，没有手改 vendor bundle。
- **路线身份**：旧样本中两次发布有相同 renderer document.id，曾导致列表 key 重复、位置关联不唯一。正式路线的列表/导航/位置用持久资源 ID；文档内容不改写。旧文档 ID 仅在唯一匹配时兼容读取位置，不能任选一个。增加库/HTTP 测试覆盖同文档 ID 的两条路线位置隔离及越权拒绝。
- **窄屏与焦点**：窄屏自动收起侧栏，展开为遮罩式导航，不挤压输入框；返回历史后关闭遮罩。Escape 不再无条件把编辑焦点移到账号按钮。3D 提示去掉旧解锁措辞和开发说明。
- **正式环境贴图**：HTTPS 镜像实测发现 `connect-src 'self'` 拦截 GLTFLoader 对浏览器内 blob 贴图的 fetch，开发环境没有此限制。仅给 connect-src/img-src 加 blob，脚本依然只同源；重新构建 Caddy 镜像后，艺术字、3 条已答胶囊、3D 角色与贴图全部可见，控制台无错误。
- **防回归**：vendor 测试通过随包 source map 定位实际校验器与编译器，不再硬编码每次构建都会变化的压缩变量名；同时核对全部 19 项产物的文件集合、字节数与 SHA-256，防止遗漏或混用旧 chunk。上游位置存储 smoke 已纳入标准模块边界测试命令。
